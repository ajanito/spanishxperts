Tutorial

Language Reactor, step by step

Language Reactor is a browser extension that helps you work with subtitles while you watch supported content. What you need any tool like it to help you do:

  • Connect spoken Spanish with written Spanish
  • Pause and replay useful sections
  • Investigate unfamiliar language when necessary
  • Return to the content with greater understanding
